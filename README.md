# Натяжные потолки «ДаР» — сайт

**Демо: https://insafvibecode.github.io/potolki-dar/**

Статика: HTML + CSS + JS, без сборки и фреймворков. Открывается двойным кликом по `index.html`,
заливается на любой хостинг простым копированием папки.

> Демо на github.io — только для показа. От поисковиков оно закрыто: в `index.html` есть
> небольшой скрипт, который добавляет `noindex` на домене `github.io` и ничего не делает
> на боевом домене. Реквизиты в политике обработки данных пока не заполнены —
> см. раздел «Персональные данные».

## Как устроены заявки

**Сайт не собирает персональные данные.** Форм заявки, квиза и обратного звонка нет —
это осознанное решение, чтобы не подпадать под требования 152-ФЗ по сбору данных
(подробнее в разделе про Роскомнадзор).

Все обращения идут напрямую:

- звонок — `tel:+79648642469`
- MAX — `max.ru/potolki-dar`
- ВКонтакте — группа `vk.ru/club235965748`

Блок связи — секция `#svyaz` на главной, плюс кнопка в шапке, плавающие кнопки
на мобильном и футер.

**Калькулятор** считает целиком в браузере: ничего никуда не отправляет. Кнопка
«Скопировать расчёт и написать» кладёт смету в буфер обмена и открывает MAX —
человек вставляет текст и отправляет сам. К нам данные попадают только после того,
как он нажмёт «отправить» в мессенджере.

### ⚠️ Никнейм в MAX — заменить перед публикацией

Сейчас везде стоит заглушка `max.ru/potolki-dar`. Настоящий никнейм Руслана
можно посмотреть в приложении: Профиль → нажать на никнейм, ссылка вида
`max.ru/ваш_никнейм` появится на экране.

Заменить в двух файлах:

- `index.html` — 4 места: шапка, блок `#svyaz`, плавающая кнопка, футер
- `js/calc.js` — константа `MAX_URL`

```bash
# быстрая замена, если никнейм известен
sed -i 's|max.ru/potolki-dar|max.ru/НАСТОЯЩИЙ_НИКНЕЙМ|g' index.html js/calc.js
```

Заодно проверьте руками в обычном браузере кнопку «Скопировать расчёт и написать»:
копирование в буфер требует пользовательского клика, автоматически это не проверить.
Если браузер откажет в доступе к буферу, кнопка покажет подсказку и всё равно
откроет MAX, а смета в этот момент видна на экране — переписать можно вручную.

## Что нужно сделать перед запуском

### 1. Фото

На сайте стоят 18 фото с объектов. Оригиналы лежат в `img/_source/` — их не трогаем,
сайт использует обработанные версии.

Обработка — скриптом `_tools/prepare_images.py`: кроп под нужное соотношение, вытягивание
теней, резкость, WebP. Настройки покадровые (`JOBS` в начале файла): `anchor` двигает кроп
по вертикали, `bright` правит яркость, `pre` отрезает лишнее по краям. Поправил параметр —
перезапустил скрипт:

```bash
python _tools/prepare_images.py
```

в `index.html` (блок `<div class="works">`): вместо «Санузел с теневым профилем» ставится
«ЖК „Знак“» и так далее. То же и в `alt` — там уже есть «Ижевск», не хватает только адреса.

Блок «Кто делает» идёт без фото. Если фото Руслана появится — вернуть `<figure class="master__photo">`
в `index.html` внутрь `.master`, и вёрстка сама перестроится в две колонки (правило
`.master:has(.master__photo)` в CSS). Формат — 600×800, вертикальное.

Заглушки рисует код в конце `js/main.js` (блок «Заглушки вместо ненайденных фото») —
он срабатывает только когда файла нет.

### 2. Домен и аналитика

- В `index.html`, `policy/index.html`, `robots.txt` и `sitemap.xml` стоит домен-заглушка
  `potolki-dar.ru` — заменить на реальный
- Хостинг с российским IP, https, редирект www → без www
- Подключить Яндекс.Метрику: вставить счётчик и указать ID в `js/main.js` (`var METRIKA_ID = null;`).
  Цели `phone_click`, `max_click`, `vk_click`, `calc_copy` уже отправляются из кода —
  останется создать их в интерфейсе Метрики с такими же названиями
- Добавить сайт в Яндекс.Вебмастер, скормить `sitemap.xml`

### 3. Персональные данные (152-ФЗ)

Сайт намеренно не собирает персональные данные: форм заявки нет, калькулятор считает
в браузере, обращения идут напрямую в мессенджеры и по телефону. Это снимает вопросы
по сбору и хранению данных через сайт.

Но обязанности оператора остаются — из-за веб-аналитики. Яндекс.Метрика обрабатывает
данные посетителей (IP, cookie, поведение), а переписка с клиентами в мессенджерах —
это тоже обработка персональных данных.

Что нужно сделать:

1. **Заполнить реквизиты в политике** — `policy/index.html`. Всё, что подсвечено жёлтым
   (`class="fill-me"`), плейсхолдеры: наименование ИП или ООО, ИНН, ОГРНИП/ОГРН, адрес,
   e-mail, дата редакции. Пока они на месте, публиковать страницу нельзя.
2. **Показать политику юристу.** Документ типовой и составлен под этот сайт, но юриста не заменяет.
3. **Подать уведомление в Роскомнадзор** — см. ниже.

### Роскомнадзор

Уведомление о намерении обрабатывать персональные данные подаётся до начала обработки
(ст. 22 закона № 152-ФЗ). Подача бесплатная, онлайн:

- через портал РКН: https://pd.rkn.gov.ru/operators-registry/notification/form/
- либо через Госуслуги

В уведомлении указываются: оператор и его реквизиты, цель обработки (ответ на обращения
клиентов, заключение и исполнение договора), категории данных (номер телефона, имя),
категории субъектов (клиенты и потенциальные клиенты), способ обработки (смешанный),
место нахождения базы данных — территория РФ.

**Если когда-нибудь вернёте форму заявки на сайт**, добавится ещё три вещи: галочка
согласия перед отправкой, хранение самого факта согласия вместе с заявкой и первичная
запись данных на российском хостинге. Часть 5 статьи 18 требует, чтобы база с данными
граждан РФ находилась в России, поэтому уведомлять мессенджер можно только после того,
как заявка записана у себя на сервере, — и тем более если мессенджер зарубежный.

Ставки — в начале `js/calc.js`, объект `PRICE`. Взяты из прайса «ДаР»:

|---|---|
| Потолок под ключ (бюджетный вариант) | от 700 ₽/м² |
| Точечный светильник с разводкой электрики | 450 ₽/шт |
| Установка люстры (без сборки) | 500 ₽/шт |
| Световая линия | от 3500 ₽/пог.м |
| Теневой профиль, пластик | 350 ₽/пог.м |
| Теневой профиль, алюминий | от 1000 ₽/пог.м |
| Запил угла 45° | 350 ₽/угол |
| Трек накладной | 700 ₽/пог.м |
| Трек скрытого монтажа | 3500 ₽/пог.м |
| Магнитный трек | 4000 ₽/пог.м |
| Скрытый карниз ПК-14, пластик | 1800 ₽/пог.м |
| Скрытый карниз ПК-14, алюминий | 2800 ₽/пог.м |

Периметр для профиля калькулятор прикидывает сам из площади, как для комнаты,
близкой к квадрату, с запасом на ниши.

### Чего в прайсе не было — проверить у заказчика

В `PRICE` эти значения помечены комментарием «оценка»:

- **глянцевое полотно — 800 ₽/м², сатиновое — 850 ₽/м², ткань Descor — 1900 ₽/м².**
  Заказчик дал только бюджетный вариант (700 ₽/м²), остальное поставлено на глаз;
- **минимальная сумма заказа — 9000 ₽.** Без неё калькулятор на ванной в 4 м²
  покажет 2800 ₽, чего быть не может: выезд и работа на малой площади стоят дороже.

Ещё в калькуляторе нет парящих конструкций — цены на них в прайсе не было,
хотя в услугах они есть. Появится цена — добавлю пункт.
